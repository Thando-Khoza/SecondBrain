
# Second Brain

A Personal Knowledge Management Application Built With Python.

## About The Project

Second Brain is a personal knowledge management application designed to help users capture, organise, search and manage their notes in one place.

The project was built to demonstrate practical software development, database management and application development skills.

## Features

- Dashboard with note statistics
- Create and save notes
- Search through notes
- Organise notes by category
- Edit existing notes
- Delete notes
- SQLite database integration

## Technologies Used

- Python
- Streamlit
- SQLite

## Installation

1. Clone the repository.
2. Install the required dependencies:

   pip install streamlit

3. Run the application:

   streamlit run app.py
